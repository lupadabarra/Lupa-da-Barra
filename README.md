# Lupa da Barra

Dossiê aberto das despesas da Prefeitura e da Câmara Municipal de Barra de São Miguel, Alagoas.

- Site: https://joanasaldanha45-dotcom.github.io/lupa-da-barra/
- Dados em `data/` (JSON), atualizados automaticamente a cada 4 horas a partir de fontes oficiais.
- Alertas são sinais objetivos para checagem, não acusações.
